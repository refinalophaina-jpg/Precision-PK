# Intermittent Haemodialysis Dosing (D16) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give a pharmacist dosing a patient on IHD an HD-shaped answer:
- a post-HD dose sized on the fitted Goti-HD curve;
- an empiric loading and maintenance dose from the consensus guideline before the first level;
- a recurring schedule generator;
- a flag on a dose given during a session;
- a Trough-module guard.

**Architecture:** Everything sits in the one inline script of `index.html`, as pure functions next
to the D15 session layer (`hdSessionSummary`), then wired into `renderBayesianResults`, the HD
section markup and the Trough panel. Fits, objectives and `bayesDoseOptimizer` do not change.

**Tech Stack:** vanilla JS (single file, CSP hash-pinned, `__ACT` handler registry), Node `vm`
test harness (`phase2d_validation.cjs`), Playwright (`docs/audit/browser-flows.cjs`).

**Spec:** `docs/superpowers/specs/2026-10-02-hd-dosing-design.md`

## Global Constraints

- **Sources:** Rybak MJ et al., *Am J Health-Syst Pharm* 2020;77:835–864.
  - **Rec 11:** loading by actual body weight, ≤ 3,000 mg.
  - **Rec 13:** after dialysis ends: low permeability LD 25 / MD 7.5; high LD 25 / MD 10.
    Intradialytic: low LD 30 / MD 7.5–10; high LD 35 / MD 10–15 (mg/kg; MD thrice weekly).
  - **Rec 14:** pre-dialysis 15–20 mg/L ≈ AUC 400–600 over the previous 24 h; levels drive dosing.
  - **Text:** 20–40% of an intradialytic dose is removed by the dialyser; dose with every session.
- **Every clinical number carries its source comment** (rule 1). Preferences are marked
  `PREFERENCE (rule 8)`.
- **Rounding** to `MATRIX_DOSE_STEP` (250 mg). **Maintenance candidates** never exceed
  `DOSE_MAX_PER_DOSE_MG` (2,000 mg). **Loading** never exceeds 3,000 mg.
- **No inline `on*` handlers:** new controls use `__ACT` keys `k76`–`k78`.
- **No silent defaults:** dialyser permeability is never assumed (both rows shown); the schedule
  generator adds nothing while a field is blank.
- **Colours from tokens only.** No MHHS/institutional protocol content in the repo.
- **Engine parity** `--ref 95e3e90` must give 0 differences.

## Review Focus

1. **A session in progress now:** the next dose time is that session's end (`endH > nowH`), not
   the session after it. Test in Task 3.
2. **Planned doses already entered after the dose time:** they are part of the course. The
   recommendation counts them, and the line says the reading includes the planned doses entered.
   Test in Task 3.
3. **No dose reaches 15 mg/L** (very high clearance), or every dose overshoots: closest-and-flagged,
   never silently the cap. Test in Task 3.
4. **A schedule start date that is not itself on the pattern** (a Tuesday with MWF): the first
   session is the next matching day, never the start date. Test in Task 4.
5. **The weight extremes the limits allow** (20 kg, 400 kg): LD capped with a flag; MD above
   2,000 mg flagged. Test in Task 1.

```js
// ─── Empiric dosing on intermittent haemodialysis (D16) ───
// Rybak MJ et al. Am J Health-Syst Pharm 2020;77:835–864.
//   Rec 13 (B-II): mg/kg by dialyser permeability and timing; maintenance thrice
//   weekly, given with every session. Rec 11: loading by actual body weight,
//   not exceeding 3,000 mg. Rec 14: once a pre-dialysis level exists, levels —
//   not a weight-based dose — drive dosing.
const HD_EMPIRIC_MG_PER_KG = {
  after:         { high: { ld: 25, md: [10, 10] },  low: { ld: 25, md: [7.5, 7.5] } },
  intradialytic: { high: { ld: 35, md: [10, 15] },  low: { ld: 30, md: [7.5, 10] } },
};
const HD_LOADING_MAX_MG = 3000;   // Rec 11
function roundDose250(mg) { return Math.max(MATRIX_DOSE_STEP, Math.round(mg / MATRIX_DOSE_STEP) * MATRIX_DOSE_STEP); }
function hdEmpiricDoses(abwKg) {
  if (!(abwKg > 0)) return null;
  const rows = [];
  for (const timing of ['after', 'intradialytic']) for (const perm of ['high', 'low']) {
    const c = HD_EMPIRIC_MG_PER_KG[timing][perm];
    const ldRaw = roundDose250(c.ld * abwKg);
    const md = [roundDose250(c.md[0] * abwKg), roundDose250(c.md[1] * abwKg)];
    rows.push({ timing, perm, ldPerKg: c.ld, mdPerKg: c.md,
      ld: Math.min(HD_LOADING_MAX_MG, ldRaw), ldCapped: ldRaw > HD_LOADING_MAX_MG,
      md, mdOverCeiling: md[1] > DOSE_MAX_PER_DOSE_MG });
  }
  return rows;
}
```

```js
// AUC of the fitted curve over [t0, t1], composite Simpson. Numerical, so the
// step count is stated: 1 interval per 3 min by default (converged to <1% in SUITE 35).
function fittedAUC(r, t0, t1, n) {
  n = n || Math.max(2, Math.ceil((t1 - t0) * 20));
  if (n % 2) n++;
  const h = (t1 - t0) / n;
  let s = predictFittedAt(r, t0) + predictFittedAt(r, t1);
  for (let i = 1; i < n; i++) s += (i % 2 ? 4 : 2) * predictFittedAt(r, t0 + i * h);
  return s * h / 3;
}
// Post-HD dose (D16): the dose goes at the end of the next planned session (one in
// progress counts) and is sized at the start of the session after it, on the
// fitted curve with every dose already entered. Hold when no dose still reads ≥ 15;
// else the smallest 250 mg step landing in 15–20 (Rybak 2020 Rec 14); else the
// closest step, flagged. Maintenance never exceeds DOSE_MAX_PER_DOSE_MG.
function hdNextDose(r, nowH) {
  const planned = (r.hdSessions || []).filter(x => x.endH > nowH).sort((a, b) => a.startH - b.startH);
  if (planned.length < 2) return { need: 'sessions', planned: planned.length };
  const doseAtH = planned[0].endH, sizing = planned[1];
  const withDose = (mg) => mg > 0 ? Object.assign({}, r, { doses: r.doses.concat([{ mg, tinfH: autoTinf(mg), timeH: doseAtH }]) }) : r;
  const evals = [0];
  for (let mg = MATRIX_DOSE_STEP; mg <= DOSE_MAX_PER_DOSE_MG; mg += MATRIX_DOSE_STEP) evals.push(mg);
  const ev = evals.map(mg => ({ mg, pre: predictFittedAt(withDose(mg), sizing.startH) }));
  const gap = (e) => e.pre < HD_PREDIALYSIS_MIN ? HD_PREDIALYSIS_MIN - e.pre : e.pre > HD_PREDIALYSIS_MAX ? e.pre - HD_PREDIALYSIS_MAX : 0;
  let pick, kind;
  if (ev[0].pre >= HD_PREDIALYSIS_MIN) { pick = ev[0]; kind = 'hold'; }
  else {
    pick = ev.find(e => e.mg > 0 && gap(e) === 0);
    kind = pick ? 'dose' : 'closest';
    if (!pick) pick = ev.slice(1).reduce((b, e) => gap(e) < gap(b) ? e : b);
  }
  const rr = withDose(pick.mg), tinfH = pick.mg ? autoTinf(pick.mg) : 0;
  const repeat = [];
  let course = rr;
  for (let k = 1; k + 1 < planned.length; k++) {
    if (pick.mg) course = Object.assign({}, course, { doses: course.doses.concat([{ mg: pick.mg, tinfH, timeH: planned[k].endH }]) });
    repeat.push({ n: planned[k + 1].n, pre: predictFittedAt(course, planned[k + 1].startH) });
  }
  return { kind, mg: pick.mg, tinfH, doseAtH, session: planned[0].n, sizing: sizing.n, pre: pick.pre,
    auc24: fittedAUC(rr, sizing.startH - 24, sizing.startH),
    peak: pick.mg ? predictFittedAt(rr, doseAtH + tinfH) : null,
    plannedAfter: r.doses.filter(d => d.timeH >= doseAtH).length, repeat };
}
```

```js
// Recurring sessions (D16). Calendar days at local noon, so a DST change can
// never move a session to the wrong date (no "+24 h" arithmetic, SUITE 19).
const HD_PATTERN_DAYS = { MWF: [1, 3, 5], TTS: [2, 4, 6] };
function hdScheduleDates(firstDate, pattern, everyN, count) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(firstDate || '') || !(count > 0)) return [];
  const d = new Date(`${firstDate}T12:00`), out = [];
  const days = HD_PATTERN_DAYS[pattern];
  if (!days) {
    if (!(everyN >= 1)) return [];
    for (let i = 0; i < count; i++) { out.push(localDateStr(d)); d.setDate(d.getDate() + everyN); }
    return out;
  }
  for (let guard = 0; out.length < count && guard < 400; guard++) {
    if (days.includes(d.getDay())) out.push(localDateStr(d));
    d.setDate(d.getDate() + 1);
  }
  return out;
}
function addHdSchedule() {
  const g = (id) => (document.getElementById(id) || {}).value || '';

  if (!dates.length) { if (msg) msg.textContent = 'Fill every field: pattern, first date, start time (HH:MM), length and count.'; return; }
```
